# Employee Profile Generator

A beginner Python project that generates and displays employee information using variables, strings, f-strings, type conversion, and string slicing.

## Project Description

This project creates a simple employee profile and extracts information from an employee identification code.

The program displays:

- Employee name
- Age
- Experience
- Position
- Salary
- Department code
- Year code
- Employee initials
- Employee number

## Concepts Practiced

- Variables
- Strings
- String concatenation
- `+=` operator
- Type conversion with `str()`
- f-strings
- String slicing
- Indexing

## Example Employee Code

`DEV-2026-JD-001`

From this code, the program extracts:

- Department: `DEV`
- Year: `2026`
- Initials: `JD`
- Employee number: `001`

## Technologies

- Python 3
